# Home Credit LAP Voice Agent

## Project Overview
An AI voice agent built using Retell AI to conduct preliminary eligibility checks for Home Credit's Loan Against Property (LAP) offer.

## System Prompt
The complete system prompt is available in `system_prompt.txt`.

## Test Audio Recordings
Audio recordings for the test scenarios are available in the [`audios/`](audios/) folder. The Google Drive link is provided in `audios/README.md`.

## Test Transcripts
Conversation transcripts for the test scenarios are available in the [`transcripts/`](transcripts/) folder.
